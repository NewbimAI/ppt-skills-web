# 🎯 PPT 专家团

**AI 做 PPT，不是生成问题，是工作流问题。**

一个 Claude / Codex 技能：从一篇文章、一段口播稿、一份课程内容开始，做出一套有风格、有逻辑、还能继续改的 PPT。

## 为什么做这个

市面上一键生成 PPT 的工具很多，但做出来的东西大同小异：结构没想清楚就开始画，风格全靠统一模板或随机生成，图和内容对不上，而且改起来很费劲。

问题不在"生成"这一步，在前面——**做 PPT 本来就是个工作流**：先想清楚给谁讲、讲什么、怎么排，再谈好不好看。

所以我把自己做 PPT 的整套流程，拆成八步，写成了这个技能。它不替你拍板，它帮你把每一步做扎实。你不用每一步都自己做，你只要负责其中一两处关键判断，它负责干活。

一句话：**烧 AI 的时间，省你的时间。**

## 它和别家不一样的四件事

**一、生成不是一步，是八步工作流。**
目标 → 结构 → 视觉 → 拆页 → 做每一页 → 整合 → 质检 → 回改。每一步有明确产出，其中两处会停下来等你拍板：一处是**整体大纲**（一共几页、每页讲什么，先列给你看），一处是**视觉风格**（打开选择器看图选）——不是"一键生成碰运气"，是每一步做扎实。

**二、工作流里有专门的"选风格"环节。**
第三步就是定视觉：AI 按你的稿子推荐 2-3 个风格方向让你挑，也可以打开自带的[风格选择器](#风格选择器看图选不靠猜)看图选。风格是你定的，不是随机掉落的。

**三、风格能选到"底图"这一层。**
别家选风格只选到"整套 PPT 长什么样"；这里还能给**底图单独定一种气质**——国风水墨、暗调霓虹、日系极简、复古印刷……选定后 AI 做每一页时，会按这个调性、照该页内容现场生成契合的底图。整套风格 × 底图风格，自由组合。

**四、交出来的 HTML 是真的能改的。**
成品页面里自带一层编辑器：改文字、拖位置、调字号、换配色、随时撤回，全在浏览器里完成，不用回来找 AI 重新生成。改到满意，一键导出去掉编辑器的「纯净放映版」交给正式场合。以前生成的老 PPT 没有编辑器？`node assets/inject-edit-layer.mjs 你的deck.html` 一句话补装上。

## 它能帮你做出什么

| 交付形态 | 是什么 | 适合场合 | 大概多久 |
|---|---|---|---|
| **可编辑 HTML PPT**（默认） | 单文件网页，浏览器直接放映，自带一层编辑器——字号、位置、配色、文案你自己随手调 | 路演、课程、直播、内部分享 | 首版 20–40 分钟（含两次你拍板的环节） |
| **图片版** | 一页一张 PNG | 小红书图文、公众号配图、不方便开网页的场合 | 在 HTML 版基础上 +5–10 分钟 |
| **可编辑 PPTX** | 文字是真的文本框，不是图片 | 必须交 .pptx 的甲方、要二次编辑的同事 | 在 HTML 版基础上 +10–20 分钟 |

## 什么时候用它，什么时候别用

| ✅ 适合你 | ❌ 别用它 |
|---|---|
| 手上有稿子（文章 / 口播 / 课件），要变成**能讲出口**的 PPT | 只想 30 秒随便出一版应付一下——一键生成工具更快 |
| 在意风格，受不了"一眼 AI"的模板脸 | 要的是传统 .pptx 母版流水线（母版、占位符、企业模板套装） |
| 交付后还想**自己动手改**字号、位置、文案 | 只想下载现成模板图库——这里的风格是配合流程用的，不是素材站 |
| 愿意在整体大纲和风格方向上花两分钟拍板 | 完全不想参与决策——它每次都会停下来问你两次 |

## 怎么装

它就是一个文件夹，丢进 Claude 的技能目录就行。几种方式随便选：

**方式〇 · 一行命令（推荐）**

```bash
npx skills add https://github.com/ThunderOne18/ppt-expert-team
```

**方式一 · 直接跟 AI 说**

```
帮我把 https://github.com/ThunderOne18/ppt-expert-team clone 到
~/.claude/skills/ppt-expert-team/，我要能用 /ppt-expert-team 调用。
```

**方式二 · 自己 clone**

```bash
git clone https://github.com/ThunderOne18/ppt-expert-team ~/.claude/skills/ppt-expert-team
# 国内慢的话：前面加 https://gh-proxy.com/ ，或直接下 ZIP 解压
```

**方式三 · 只在某个项目里用**

```bash
cp -r ppt-expert-team <你的项目>/.claude/skills/ppt-expert-team
```

装完重启 Claude Code，敲 `/` 能看到 `ppt-expert-team` 就成了。

## 怎么用

装好后，把你的稿子丢给它，说一句：

```
用 PPT 专家团，把这篇做成 PPT。
```

接下来它会这样走——你只需要参与前三步，剩下的它自己跑完：

**① 先问你三件事（就是下 brief）**
给谁讲、什么场合、你想让对方记住哪一句。答完它开始干活。

**② 拍板一：整体大纲**
它通读你的全文，但不会直接开画，而是先给你一份「**页面地图**」——整套 PPT 一共几页、每一页讲什么、完成什么任务、大致用什么类型的版式，一页一行列给你看。你点头了才往下走。大纲错了后面全白做，所以这里必须停。（每页内部具体怎么排版，是后面拆页分镜的事，AI 自己搞定，不用你操心。）

**③ 拍板二：视觉风格（这时候风格选择器登场）**
它会把**风格选择器**的本地路径发给你——这是一个随技能装进你电脑的网页，双击就开。你在里面选两样：**整套 PPT 风格**选一个、**底图气质**选一个，点「复制参考组合」，把那句话粘回对话。这里可能涉及到每一页要配不同的图，所以你也可以同时告诉你的 AI ，根据每页内容和页面结构，把底图及配图的提示词一起写了。选择器长什么样、里面有什么，[下一节](#风格选择器看图选不靠猜)细说。

**④ 然后就不用管了**
拆页、做每一页、整合、质检，它闷头跑完，交给你一套**自带编辑器的 HTML PPT**（可编辑版）。

**⑤ 最后你自己动手调**
在页面里直接改字、挪位置、调字号配色，改到顺眼导出「纯净放映版」交出去。怎么改，[后面有一节](#交付之后在页面里自己改)专门讲。

**⑥ 还要交 .pptx？一句话的事**
HTML 定稿后跟它说"把这份输出成 PPTX"。它会**严格按照定稿的每页排版、字体、字号、配色**，分层装配出一份**可编辑的 .pptx**——文字全是真文本框，及分层图片，拿到 PowerPoint / Keynote 里还能继续改。

## 风格选择器：看图选，不靠猜

它是一个**随技能一起装进你电脑的本地网页**（`assets/style-picker/index.html`），零依赖、双击就开——走到拍板二时，AI 会主动把这个路径发给你；你也可以随时自己打开。风格是看着选的，不是文字描述里猜的。

![风格选择器](docs/images/style-picker.png)

在里面你要选两样东西，选完一起复制：

**第一样 · 整套 PPT 风格。** 内置六套我做的原创样张，**中文为主、英文为主各三套**——有的稿子适合大中文标题压场，有的适合大英文标题显质感。每套都能点开放大预览、方向键翻页：

| 赛事速度                                     | 中式人文                                   | 商务蓝白                                      |
| ---------------------------------------- | -------------------------------------- | ----------------------------------------- |
| ![](docs/images/tpl-raysir-zh-speed.png) | ![](docs/images/tpl-raysir-zh-ink.png) | ![](docs/images/tpl-raysir-zh-report.png) |
| 赛事 / 汽车 / 发布会                            | 人文 / 思想 / 讲义                           | 策略汇报 / 方法论                                |

| 瑞士黑白                                            | 咖啡暖调                                        | 奶油粗衬线                                       |
| ----------------------------------------------- | ------------------------------------------- | ------------------------------------------- |
| ![](docs/images/tpl-raysir-swiss-editorial.png) | ![](docs/images/tpl-raysir-warm-coffee.png) | ![](docs/images/tpl-raysir-cream-serif.png) |
| 方法论 / 知识分享                                      | 营销 / 课程 / 口播                                | 人文 / 品牌 / 讲义                                |

**第二样 · 底图气质。** 切到「底图库」一栏，是我用 GPT Image 攒的一批底图风格——国风水墨、暗调霓虹、日系极简、复古印刷……选一种当"气质锚点"，做每一页时 AI 会照这个调性、按该页内容现场生成契合的底图：

![底图库](docs/images/style-picker-baseimages.png)

两样都选好，点底部「**复制参考组合**」，得到一句完整指令，粘回对话，AI 就照这组方向往下做。选了会记住（刷新不丢），想换随时重选。

**想让选择器更丰富**：后排那几张灰色的「🔒 需安装」，是我很喜欢的几位博主的开源风格——[归藏](https://github.com/op7418)、[Zara](https://github.com/zarazhangrui)、[花叔](https://github.com/alchaincyf)、[lewis 的 HTML-PPT](https://github.com/lewislulu/html-ppt-skill)。这个仓库里没有他们的文件，你点卡片上的「去安装」，到他们那儿按官方方式装好，再回到 `styles.js` 把那张卡片的路径填上，灰卡就点亮成能预览的了。装得越多，你的选择器越丰富。别忘了在GitHub上给这些开源自己skills的作者们点🌟。

具体怎么加风格、怎么配底图，都写在 [风格选择器使用说明](references/style-picker-guide.md) 里。

## 交付之后：在页面里自己改

跑完八步，你拿到的不是一张"看起来像 PPT 的图"，而是一个**自带编辑器的网页**。点「编辑模式」，就能像改文档一样改它：

![可编辑 HTML 层](docs/images/editable-html-layer.png)

- 点中任意文字框：改文字、拖位置、缩放大小
- 浮动面板上调字号、字体、行距、字距、对齐、文字颜色、底色和透明度
- 改错了 Cmd/Ctrl+Z 撤回，还有全局调参面板
- 随时点「放映」全屏过一遍效果

改到顺眼后，工具条上两个导出按钮：**「保存为可编辑版」**下载一份带着你所有修改、还能继续改的新 HTML（浏览器不能直接覆盖本地原文件，所以保存=下载新文件）；**「纯净放映版」**下载去掉编辑器的干净版本——这份才是发给外部、正式放映用的。

以前生成的老 HTML PPT 没有编辑器？一句话补装：

```bash
node assets/inject-edit-layer.mjs 你的deck.html   # 生成 你的deck.editable.html，原文件不动
```

### 还要 .pptx？让它照着定稿"翻译"一份

很多场合最后还是得交 .pptx。HTML 定稿之后，跟 AI 说一句"把这份输出成 PPTX"，它会以你改好的 HTML 为唯一标准，**严格按照每一页的排版、字体、字号、配色**，把内容分层装配进 .pptx：

![分层可编辑 PPTX](docs/images/layered-pptx.png)

底图、配图、结构图、文字各归各层，**文字全部是真文本框**——不是"一页一张截图"的伪 PPT，也不是 PDF 转出来那种文字碎裂错位的残次品。拿到 PowerPoint / Keynote 里，改字、挪位置、换图，都还能继续。



## 几条我踩过坑才总结出来的规矩

这些是这套流程里最要紧的经验，也写进了技能，AI 会照着做：

1. **图要跟内容对得上。** 讲联合国会员国就配世界地图，别甩个游戏地形图上来凑数。
2. **讲稿用第一人称，张嘴能念。** 写"接下来我讲讲 X"，不写"下面由 X 收束"这种舞台说明。
3. **字体按稿子的调性选，别用大路货。** 标题用有性格的字，正文用稳的黑体，字体链尾永远留个兜底字，换台电脑不崩。
4. **中文标题换行只在标点处断，绝不把一个词拆两半。** 这条我尤其在意。
5. **草稿就是草稿，别把规划说成成品。**
6. **借别人的 IP 做包装，借的是它的页面风格和结构逻辑，不是把它的画面贴上来当背景。**

## 它做不到的

先把丑话说前面，省得你装完失望：

- **底图生成要看你环境里有没有生图能力**（GPT Image / 其他生图工具）。没有的话它不会硬凑，会退回纯排版方案——依然能看，但少了底图那层氛围。
- **外接博主的风格不在这个仓库里。** 归藏、Zara、花叔的东西要去他们仓库自己装，并遵守各自的协议（归藏是 AGPL-3.0，别再打包分发）。别忘了给这些开源自己skills的作者们点🌟。
- **HTML 转 PPTX 有保真度边界。** 复杂动效、交互组件、特殊排版进了 .pptx 会被简化，PPTX 版以"文字可编辑、版式过得去"为目标，不承诺像素级还原。
- **仓库约 39M，大头是 31M 字体。** 这是故意的：12 套免费可商用字体全部内置，换台电脑、断了网，字体照样不崩。嫌大可以删掉 `assets/fonts/` 里用不到的目录。
- **它不适合赶时间。** 两次停下来等你拍板是设计出来的，不是 bug。

## 常见问题

**Q：国内 clone 慢 / 失败怎么办？**
git 命令前面加 `https://gh-proxy.com/`，或者直接下 ZIP 解压丢进技能目录。

**Q：不打开风格选择器能用吗？**
能。选择器只是"看图选"的可选入口，默认走"文字选"：AI 读风格索引给你 2-3 个推荐方向，你回复一个就行，全程不依赖任何网页。

**Q：只有 Claude Code 能用吗？**
主要为 Claude Code 设计。Codex 或其他 agent 可以把 SKILL.md 当作系统提示词用，或用第 3 步生成的「项目执行提示词」直接在任意对话里执行。

**Q：为什么我的成品字体和样张不一样？**
检查 HTML 里字体路径是不是指向了 `assets/fonts/`。字体链尾都留了兜底字体，路径断了不会崩，只会退回系统黑体。
