        拿到手之后
        
怎么筛 · 怎么装 · 怎么在 Agent 里用

      


      

        

          
1四步筛出候选

          
    
            
  1. 定路线：对方要编辑 → PPTX；否则 → HTML。
    2. 
            
  2. 看层级：S = 5k+ star 规模验证，A = 100–5k 实用候选，B = 新/小众。
    3. 
            
  3. 对能力：要「→ PPTX / 数据图表 / 演讲者模式」就点亮对应能力筛选；· 只代表文档没写，不等于不支持。
    4. 
            
  4. 查许可：商用与闭源场景优先 MIT / Apache；标 Copyleft 的先看协议。
    5. 
          

          
搜索框支持名称、简介、repo、风格 ID；/ 聚焦搜索，Ctrl K 打开全局面板。

        


        

          
260 秒做出同款

          
    
            
  1. 抄风格 ID：样图下等宽字，如 soft-editorial。
    2. 
            
  2. 点风格标签复制提示词：图库卡片、详情页的风格标签一点就复制出完整提示词 —— 里面写好了 Skill 来源和安装命令，Agent 会先查装没装、征得你同意再自动装。
    3. 
            
  3. 写进提示词：风格 ID 不是命令行参数，是人话的一部分：
    4. 
          

          
用 soft-editorial 这个模板，把 docs/roadmap.md 做成一份 12 页的 deck，
面向投资人，我会现场讲，所以每页字少一点。

          
点名风格 ID = 跳过预览挑选环节；想让它先给几个选项，就别点名，直接说「帮我做一份关于 X 的 deck」。复制出的提示词按风格 ID 个性化：带 Skill 来源、安装检查与该风格的专属要点，主题 / 受众用【】占位替换即可。

        


        

          
3在 Workbuddy 等各类 Agent 里用

          

            

              
通用三件事

              
    
                
  1. 拿到 skill：详情页复制安装命令，或直接 git clone / 下载 zip。
    2. 
                
  2. 放对位置：skill = 一个含 SKILL.md 的目录，放进你所用 Agent 的 skills 目录或插件市场（Claude Code 是 ~/.claude/skills/；跨 agent 可用 skills-cli 安装器；Workbuddy 等以各自「技能 / 插件」入口为准，认目录不认命令）。
    3. 
                
  3. 自然语言触发：不用记参数，直接说需求 +风格 ID，Agent 会按该 skill 的 SKILL.md 执行。
    4. 
              

            

            

              
触发模板（改人话即可）

              
我要做一份给投资人的 deck（HTML 路线，不用改源文件）。
用 frontend-slides 的 soft-editorial 风格，12 页，每页字少一点，
结尾要有一页数据图表。先给我 3 个预览我来指。

              
把这个登记册本身装成 skill，agent 会先问路线问题、再报安装命令与风格 ID：

              /plugin marketplace add brycewang-stanford/many-ppt-skills（Claude Code 会话内）
